# Personal portfolio

My personal portfolio website, built with React, TypeScript, and Vite.
The starter demo has been replaced with a minimal page ready to customize.

## Getting started

Install dependencies after cloning with `npm install`.
Run `npm run dev` and open the local URL printed in the terminal.
Changes to source files appear automatically. Press Ctrl+C to stop the server.

## Commands

- `npm run dev`: start the development server.
- `npm run build`: check TypeScript and create the production site in `dist/`.
- `npm run lint`: check code with Oxlint.
- `npm run preview`: serve the production build locally after building.
- `npm.cmd test`: will watch for changes and rerun tests

## Project structure

- `src/App.tsx`: main page content.
- `src/App.css`: page styles.
- `src/index.css`: global styles.
- `src/main.tsx`: React entry point.
- `index.html`: page title, description, and HTML entry point.
- `public/`: future static assets, such as a favicon or CV.

Keep `package-lock.json` committed so dependency versions stay consistent.
Generated files in `node_modules/` and `dist/` are ignored by Git.
